# Review Checklist - Inherent Safety, Siting and Layout

- [ ] Ask whether inventory, hazardous material, energy, pressure, temperature, complexity, congestion, or human reliance can be eliminated, minimized, substituted, moderated, or simplified.
- [ ] For siting/layout, review occupied buildings, separation, drainage, access/egress, escalation paths, congestion, emergency response, and vulnerability to fire/explosion/toxic effects.
- [ ] Prefer source reduction and layout changes before alarms/procedures/SIS when feasible; document why options are accepted or rejected.

## Final QA

- [ ] Project-specific data were used where required.
- [ ] Missing basis is explicit.
- [ ] Dependencies/common-cause issues are visible.
- [ ] Recommendation is action-oriented and auditable.
- [ ] Source slugs are cited.
