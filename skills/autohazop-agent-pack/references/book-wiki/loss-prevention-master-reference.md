## Routing role

Use Lees as a broad source map for hazard identification, assessment, prevention, mitigation, fire/explosion/toxic hazards, equipment hazards, and management controls.

## Use limits

For a final answer, route to the narrower wiki/skill when available: HAZOP, LOPA/SIS, relief/consequence, QRA, reliability, PSM/MOC, or incident learning.

## AutoHAZOP role

Use as a secondary retrieval source for terminology, cross-checks, and missing hazard prompts when a narrow source is silent.

## Answer Pattern

When using this wiki, answer with:

- `Decision`: the best current engineering decision or review status.
- `Basis`: source slug(s), page count/source note, and assumptions.
- `Missing data`: project criteria, tags, drawings, calculations, inspection/proof-test evidence, or data tables needed.
- `Cautions`: dependency, uncertainty, applicability, or OCR/manual-lookup limitations.
- `Next action`: specific review, calculation, field check, or documentation update.
