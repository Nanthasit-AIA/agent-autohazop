# Review Checklist - PSM, RBPS, MOC and Documentation

- [ ] Classify gaps by process knowledge, hazard identification, procedures, training, mechanical integrity, MOC, emergency management, audit, culture, and action tracking.
- [ ] For MOC, require trigger, scope, technical basis, hazard review, authorization, temporary/permanent classification, PSSR, training, document updates, and closeout.
- [ ] For documentation, require owner, revision, source, retention, traceability, and audit basis for safety-critical assumptions.

## Final QA

- [ ] Project-specific data were used where required.
- [ ] Missing basis is explicit.
- [ ] Dependencies/common-cause issues are visible.
- [ ] Recommendation is action-oriented and auditable.
- [ ] Source slugs are cited.
