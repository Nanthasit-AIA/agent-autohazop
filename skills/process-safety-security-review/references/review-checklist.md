# Review Checklist - Process Safety and Security Review

- [ ] Separate accidental process safety scenarios from intentional threat/security vulnerability scenarios while keeping common consequences and safeguards visible.
- [ ] Check asset attractiveness, threat, vulnerability, consequence, existing security measures, emergency response, and management-system ownership.
- [ ] Do not mix security safeguards into LOPA IPL credit without independence, effectiveness, and auditability evidence.

## Final QA

- [ ] Project-specific data were used where required.
- [ ] Missing basis is explicit.
- [ ] Dependencies/common-cause issues are visible.
